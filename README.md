# Employee Salary Prediction

## Project Overview
This project predicts employee salaries based on years of experience using Machine Learning.  
A Linear Regression model is trained on the dataset to understand the relationship between experience and salary.
The project demonstrates:
1. Data preprocessing
2. Data visualization
3. Regression analysis
4. Model evaluation
5. Salary prediction

# Technologies Used
1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Scikit-learn

# Machine Learning Algorithm Used
## Linear Regression
Linear Regression is used to predict continuous salary values based on employee experience.

# Dataset Information
1. YearsExperience - Number of years of experience
2. Salary - Employee salary
